# 界面本地化

程序内置简体中文。把 UTF-8 `.lng` 文件放在 exe 同目录，基础文件名与 exe 相同即可加载：`DesktopTwin.exe` 对应 `DesktopTwin.lng`。重新启动后生效，移走该文件恢复内置文字。

`DesktopTwin-0.2.9-EN.lng` 是仓库保留的英文样例，部分文字随行为更新；文件名不代表它与当前源码的全部键一一对应。缺失或空值会回退中文，旧键可能不再使用，不承诺固定条数或满译。

## 生成模板

在单独的工作目录运行：

```powershell
.\DesktopTwin.exe --export-lng
```

该入口在创建正常应用窗口之前处理，在当前工作目录写出与程序基础名相同的 `.lng`，然后退出。程序会尝试备份已有同名文件，但备份失败仍可能继续覆盖，因此请保留译文副本。

## 编辑与核对

```ini
# 注释
Main.Title=Desktop Twin
Main.Start=Start
```

只改等号右侧，保留键名和 `{0}` / `{1}` 占位符。支持 `\n`、`\t`、`\\` 转义；键不区分大小写，重复键以最后一次有效值为准。

重新启动后检查日志中的语言文件路径和缺失条目。升级后重新导出模板对照补齐，不把固定条数写成长期保证。按 Shift 打开诊断窗口可查看未触发的检查项，便于核对译文。

语言内容与功能事实都需要更新：如果切换流程已改变，即使旧键仍能加载，原有“秒切”“自动无限恢复”等译文也不再准确。提交译文时说明对应源码提交与已核对范围。
