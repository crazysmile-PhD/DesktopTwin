# v0.3.2（未发布）

新增“控制中心 → 相对鼠标（实验性）”，默认关闭，设置会保存；切换时重连 RDP，没有连接时留到下次连接。原生输入需要支持该能力的 Windows 11 24H2 或更新系统及 RDP 控件/服务器。

程序在连接前配置 `AllowRelativeMouseMode` 与 `RelativeMouseMode`，不受支持时尽力恢复两项属性并继续连接。登录完成后区分请求已接受与设置不可用；日志记录接受情况和鼠标输入模式回调。没有额外代理输入转发。

## 验证边界

- 自动测试覆盖开关设置持久化、复用控件后的模式清理、不支持属性、部分配置失败、清理失败及反射包装的 COM 异常。
- 在 Windows 构建 26300、`mstscax.dll` 文件版本 `10.0.26100.9949` 上，用真实 MsRdpClient10 控件调用生产配置路径，验证两项属性可以打开、回读与关闭。可用 `dotnet run --project tests/DesktopTwin.NativeSmoke/DesktopTwin.NativeSmoke.csproj -c Release` 复现。该检查没有建立 RDP 连接，不证明服务器协商、鼠标锁定或游戏转视角成功。
- 尚未完成真实 Child Session 中的游戏、窗口/全屏、观看模式、失焦与 UU 串流输入验证。不声明兼容全部游戏或旧系统，不包含性能提升承诺。

若游戏操作异常，可取消该选项并等待重连完成。日志和反馈步骤见 [排查手册](../../docs/troubleshooting.md#鼠标转视角)。
