# v0.3.1

本版修复连接、注销、切换主机与 UU 锁定互相干扰造成的等待和错误状态，删除重复的后台恢复流程，并重写使用与排查文档。

## 更新内容

- 注销、断开或切换主机会作废旧连接意图；旧任务与延迟重试不能重新启动已取消的会话。注销不再等待会话内程序启动返回，诊断采集和代理启动的耗时部分移出界面线程。
- UU 操作统一串行，手动命令优先。删除无限恢复和切换主机后的后台回连；视角锁定最多尝试三次纠正，并在尝试之间退避。热键通过文件通知即时处理，保留低频轮询作为补充。
- 连接前自动尝试 RDP 共享帧缓冲与硬件模式，分别处理系统不支持的属性；无需新增用户开关。属性被接受不代表实际使用了 GPU，也不保证提高游戏帧率。
- 设置重连每次尝试最多等待 60 秒；缺少连接回调时结束等待并保留待应用设置，避免永久停在重连中。
- 更新 README、架构、性能排查、修复边界及反馈链接。上游历史发行说明保留原文与来源，当前使用方式以新版文档为准。

对应修复：[PR #1](https://github.com/crazysmile-PhD/DesktopTwin/pull/1)、[PR #2](https://github.com/crazysmile-PhD/DesktopTwin/pull/2)、[PR #3](https://github.com/crazysmile-PhD/DesktopTwin/pull/3)、[PR #4](https://github.com/crazysmile-PhD/DesktopTwin/pull/4)、[PR #5](https://github.com/crazysmile-PhD/DesktopTwin/pull/5)。

## 下载与升级

- **DesktopTwin-0.3.1.exe**：Windows x64，自带 .NET 运行时。
- **DesktopTwin-0.3.1-NET10.exe**：Windows x64，需要安装 .NET 10 桌面运行时。
- **README.txt**：运行条件、两个程序的 SHA-256 校验值与反馈入口。

退出旧版后运行新版即可；沿用原来的本机设置与凭据存储，不要求重置配置。程序仍要求管理员权限；系统 Child Session、RDP 与目标程序本身的限制仍然适用。

## 验证范围

Release 构建将警告视为错误，并执行 113 项单元测试、XAML 与常量检查。自动检查不覆盖真实 RDP 会话、UU 服务或游戏画面。本版没有真实游戏帧率、GPU 使用率或跨机器延迟基准，不承诺固定的性能提升。
